# Chau Agent Skills

Personal ChatGPT/Codex plugin containing the six skills from
`skills/chatgpt-agents/`:

- `hono-stack`
- `jp-comm`
- `jp-requirement`
- `meo-pptx`
- `premium-web`
- `seo`

The canonical editable skill source remains `skills/chatgpt-agents/`. Before publishing an
update, copy those six folders into this plugin's `skills/` directory, validate both the source
edition and plugin, then reinstall the personal plugin so the new version is picked up.
